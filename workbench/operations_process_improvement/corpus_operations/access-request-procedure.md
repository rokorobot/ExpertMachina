# Access Request Procedure

Meridian Operations Ltd — Standard Operating Procedure OPS-AC-02.
This procedure governs how system access is requested, approved, and
provisioned. All content is illustrative and fictional.

## Purpose

This procedure defines how an employee or manager requests access to a
Meridian system and how that request is reviewed and provisioned.

## Process steps

Step 1. The requester submits an access request naming the system and
the access level. On submission the request is routed to the resource
owner for review.

Step 2. The resource owner reviews the access request. Staff system
access requests must be approved within 5 business days of the request.
When the resource owner approves, the request is routed to the IT team
for provisioning.

Step 3. The IT team provisions the approved access. After provisioning
the access record is updated.

## Revocation

When access is no longer required the access record is marked for
revocation. The marked record is then closed out.
