# ExpertMachina Product Roadmap

Having completed MVP 0.2 (Governance & Lifecycle Control), the next milestone centers around transforming ExpertMachina from a knowledge preparation factory into an interactive, trustworthy query console.

---

## MVP 0.3 — Evidence-Backed Ask Expert Console

The primary objective of MVP 0.3 is to allow operators to ask natural language questions directly against the approved knowledge base, backed by strict grounding constraints.

### Core Architecture

```text
Question
    ↓
Approved Assets Only (Ignore Candidate, Rejected, Archived)
    ↓
Evidence Retrieval & Vector Similarity Matching
    ↓
Context Grounding (Verify Source Hash & Status)
    ↓
Answer + Citations (Document, Page, Section, Hash)
```

---

## 1. Grounding Rule: "No Evidence = No Answer"

Unlike typical Retrieval-Augmented Generation (RAG) systems that hallucinate answers or fallback to general-purpose LLM weights when search results are weak, ExpertMachina MVP 0.3 enforces a strict governance constraint:

- **Strict Retrieval Thresholds**: If no relevant, approved knowledge assets are retrieved above a configured vector similarity threshold, the model is forbidden from answering.
- **Explicit Fallback**: The system will return: *"No approved evidence could be found to answer this question."*
- **No Direct Model Knowledge Access**: System prompts will isolate the LLM from utilizing external web or training knowledge, enforcing that context is the *only* source of truth.

---

## 2. Evidence-Backed Citations

Every successful response generated by the console must list complete citation cards containing:
1. **Source Document Name**: Clickable link to view the file.
2. **Page & Section Headings**: Precise locator information.
3. **Cryptographic Hash**: Block hash verification verifying that the source text has not been modified since it was parsed.
4. **Lifecycle Status**: Verification that the asset remains in an active `APPROVED` state.

---

## 3. Audit Logging of Console Queries

- All operator questions and corresponding returned answers (along with retrieved evidence IDs) are committed to the immutable audit log table.
- Any attempts to query archived or rejected assets through custom API parameter overrides will trigger security/governance alert events.
